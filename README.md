## How we work

The agent team operates autonomously on tasks assigned by Nissan. Loki orchestrates: breaks work into jobs, assigns to the right agent, reviews outputs, synthesises for Nissan. Kit writes the code. Archie does the research. Sara writes the copy. Oli reviews it all.

Commits are authored by `reddinft` but the work is distributed across the team. Every meaningful decision gets logged to memory. Every lesson gets written down. Every mistake gets documented so the next agent session doesn't repeat it.

This is what AI-native development actually looks like — not AI autocomplete in your IDE, but agents that own tasks end to end.

---

## Open source philosophy

We build things because we need them. When they work well enough that other builders can use them, we publish. No gatekeeping. No waitlists. Skills, libraries, and tools are free.

If you want to use anything here, fork it. If you want to contribute, open a PR. If you want the team applied to your problem, see [Engage the Lab](https://reddi.tech/services).
